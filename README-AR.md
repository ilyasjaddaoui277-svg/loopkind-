# نشر معاينة Loopkind على GitHub Pages

## رفع الملفات

1. فك ضغط `GitHub-Pages.zip` على جهازك.
2. ارفع **محتويات** المجلد إلى جذر المستودع؛ يجب أن يكون `index.html` في مستوى الجذر، وبجانبه مجلد `assets/` وملف `Documentation.html`.
3. افتح المستودع في GitHub ثم **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واحفظ الإعداد.
5. بعد انتهاء النشر افتح الرابط الذي يعرضه GitHub Pages. إذا ظهر 404، تحقق من أن اسم الملف `index.html` بحروف صغيرة، وأنه ليس داخل مجلد فرعي، وأن مجلد `assets/` رُفع كاملًا.

## ما تعرضه هذه الصفحة

واجهة `index.html` إطار عرض بصري مستوحى من المتصفح، وتتيح التبديل بين لقطات فعلية من تثبيت WordPress الاختباري: الصفحة الرئيسية، القصة، خطوات إعادة التعبئة، وصفحة منتج WooCommerce.

هذه **معاينة ثابتة بالصور فقط**. GitHub Pages لا يشغّل PHP أو WordPress أو WooCommerce، لذلك لا يوجد متجر أو سلة أو Checkout حي. إذا طلب ThemeForest رابط Live Preview تفاعليًا، استضف نسخة WordPress مستقلة على استضافة تدعم PHP وقاعدة بيانات، واستخدم عنوان تلك النسخة.
